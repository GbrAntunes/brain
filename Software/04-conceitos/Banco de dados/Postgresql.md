[[Sistema gerenciador de banco de dados - SGBD]] objeto-relacional de código aberto que estende a linguagem [[SQL]].
### Por que usar Postgres
- Extremamente extensível, permitindo criar seus próprios tipos de dados, criar funções personalizadas e até usar diferentes linguagens de programação.
- Versátil. No [[Teorema PACELC]], você pode customizar o Postgres para que ele assuma um papel ou outro, a depender da sua necessidade.
