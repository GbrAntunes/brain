Um banco de dados é qualquer base de dados. Uma planilha, um infográfico, um papel com anotações, etc.
Um SGBD (Sistema gerenciador de banco de dados) é um sistema que fornece meios para alterar, editar, atualizar, etc. uma base de dados. Geralmente fornecem um ambiente poderoso para criar backups, salvar queries, tabelas entre outros. Uma solução completa para gerenciar de forma otimizada uma base de dados que pode ser relacional, não relacional, utilizar SQL, usar javascript, YAML e por aí vai.
